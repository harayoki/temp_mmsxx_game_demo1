# online/ — 公開しない実装の置き場

**このフォルダは、ソースを一般公開するときに丸ごと外す。**
外部のサーバへ実際にデータを送る実装だけをここに入れておき、
公開用のリポジトリには「送らない版」だけが残るようにする。

## 決まり

| ここに入れる | ここに入れない(= 公開する) |
|---|---|
| サーバへ記録を **送る / 取る** コード | 手元(localStorage)に保存するランキング |
| 画像や動画を **サーバへ上げる** コード | 画像と文言を**見せるだけ**のシェア画面 |
| 宛先の URL、鍵、送信の作法 | 上のものを呼ぶ側(ゲーム本体) |

見分けかたは「**外へ出て行くか**」の 1 点。
外へ出て行かないなら、それは公開してよい実装。

## 外したときにどうなるか

**ゲームは動く。** 読み込みは動的 import にしてあり、
このフォルダが無ければ手元の保存に落ちる。

| 実装 | 外したときの動き |
|---|---|
| [ranking-remote.js](ranking-remote.js) | ランキングが localStorage のままになる |

繋ぎ目は `game/main.js` の `makeRemoteRankSource()` **1 か所だけ**。
ここが `await import('../online/ranking-remote.js')` に失敗すると
`LocalRankingSource` を返す。コンソールに断りを出すが、遊びは止まらない。

`build-deploy.ps1` も `online/` があるときだけ配布物へ入れる。

## 新しく足すときは

1. 実装をこのフォルダに置く
2. 呼ぶ側は**動的 import + 失敗したときの受け皿**にする
   (受け皿は「何もしない」でも「手元で済ませる」でもよい)
3. この表に 1 行足す

## SNS シェアについて

いまのシェア画面(`game/main.js` の `share*`)は、**絵と文言を見せて
クリップボードへ渡すところまで**しかやっていない。外へ出て行かないので
そのまま公開してよく、このフォルダには何も無い。

将来サーバへ画像を上げる実装を足すときは、**その送信部分だけ**をここへ置く。
外したときは「受け付けるが何もしない」に落ちるようにして、
シェア画面そのもの(絵の選択・文言・コピー)は公開側に残す。
