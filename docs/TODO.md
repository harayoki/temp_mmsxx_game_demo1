# J. エンジン(スマホ対応を始めてから着手する)

## J-1. 表示スケールの選択

- 既定は **1 / 2 / 3 倍から選ぶ**(整数倍なのでピクセルパーフェクト)
- 別に「**画面に合わせて伸ばす**」も用意する
- 端末の画面サイズから既定値を決め、あとから設定で変えられるようにする
- `devicePixelRatio` を見て、canvas の実ピクセルと CSS サイズを分けて扱う

```js
mmsxx.setScale(2);          // 整数倍
mmsxx.setScale('fit');      // 画面に合わせて伸ばす
```

## J-2. バーチャルパッド(タッチ操作)

**設計は [SMARTPHONE.md](SMARTPHONE.md) にまとめた**(別セッションで実装する)。
決まっているのは次のとおり。

- GUI は **DOM**。横画面の左右の空きに置く(ゲーム画面には重ねない)
- 十字は **位置が移動する相対型**(触れたところが原点)
- ショットは **こすり打ち**。80 年代シューティングのオマージュなので、
  **連射は腕前のままにする**(押しっぱなしの自動連射にはしない)。
  数えかた(領域に入った瞬間 / 動いた量 / 触れた瞬間)は**未定**
- **PC ではキーボードを残す**(スマホで受けるかは未定)
- 縦持ちのときは **90 度回して横で見せる**(「横にしてください」とは出さない)
- エンジンの `Input` に `setVirtual()` を足すだけで、ゲーム側は書き換えない

未決: **こすり打ちのやりかたと伝えかた**、長押しの扱い、ポーズ以外のボタン、
スマホでのキーボード入力。
