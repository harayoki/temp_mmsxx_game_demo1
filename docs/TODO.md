# J. エンジン(スマホ対応を始めてから着手する)

> J-1 〜 J-3 は**スマホ対応に取りかかるとき**にまとめてやる。それまでは触らない。


## J-1. 表示スケールの選択

- 既定は **1 / 2 / 3 倍から選ぶ**(整数倍なのでピクセルパーフェクト)
- 別に「**画面に合わせて伸ばす**」も用意する
- 端末の画面サイズから既定値を決め、あとから設定で変えられるようにする
- `devicePixelRatio` を見て、canvas の実ピクセルと CSS サイズを分けて扱う

```js
msx.setScale(2);          // 整数倍
msx.setScale('fit');      // 画面に合わせて伸ばす
```

## J-2. バーチャルパッド(タッチ操作)

**横画面プレイ前提**。縦画面だとゲーム画面が小さすぎて遊べないため。
横画面ならゲーム画面(256x192 = 4:3)の**左右に空きができる**ので、そこに置く。
ランキングと同じように、**同じインターフェースで別実装に差し替えられる**形にする。

- エンジン側に用意する(ゲームごとに作らない)
- **左に十字キー、右にボタン**。`input.isDown()` / `wasPressed()` にそのまま流し込む
- **見た目・位置はゲーム側からカスタマイズできる**。ボタンの追加もできる
- ふだんは **A / B / ESC** の 3 つ。
  ESC は START/PAUSE ではない。ポーズだけでなく**タイトルの画面送り**や
  **名前入力をやめる**のにも使う「戻る・進む」の兼用キーなので、
  ラベルもそのまま `ESC` にしておく
- **キー入力を受け付けているときだけ有効になるボタン**も置ける(今回はこれを採用。
  裏技の打ち込みや名前入力のように、入力できる場面でだけ出す)
- キーボードと併用できること(PC では自動的に隠す)

```js
msx.input.enableVirtualPad({
  buttons: [
    { id: 'KeyZ', label: 'A' },
    { id: 'Space', label: 'B' },
    { id: 'Escape', label: 'ESC' },
    // 文字入力ができる場面でだけ出るボタン
    { id: 'keyboard', label: 'ABC', when: 'textInput' },
  ],
  place: 'sides',        // 画面の左右の空きへ
});
```

## J-3. タッチ環境での文字入力
