# STAR FABLE

MMSXX Engine のサンプル、縦スクロールシューティングです。
ゲーム本体は `game/main.js`、絵・曲・出現テーブルは `assets-src/makedata.mjs` にあります。

## 操作

- カーソルキー: 移動
- SPACE: ショット(連打で即座に撃て、押しっぱなしは自動連射)
- ESC: ポーズ。ポーズ中に `Q` ＋ RETURN でタイトルへ戻る

一覧を上下に送るところ（ハイスコア・ボスラッシュのタイム・記録・タイトルのモード選択）は
**押しっぱなしで送れます**。押した瞬間に 1 行動き、少し待ってから連続します。

### 画面の外のボタン

キャンバスの**横の余白**に置いてあります（共有の絵にも録画にも写りません）。

| ボタン | 動き |
|---|---|
| 🔊 / 🔇 | 音を消す / 戻す。ALT+M と同じ。消したまま次に開いても覚えている |

キーボードのある環境では、どの画面でも次のショートカットが効きます。

| キー | 動き |
|---|---|
| ALT+P | 共有ダイアログを出す |
| ALT+M | 音を消す / 戻す |
| ALT+S | いまの画面をクリップボードへコピー |

### 共有ダイアログ

ALT+P か、記録を出したときに自動で出ます。**キャンバスの外の DOM** なので、
出ているあいだゲームは止まります。

| ボタン | 動き |
|---|---|
| POST TO X | まだ繋いでいない（押すと知らせが出るだけ） |
| SAVE IMAGE | 板に載っている 1 枚を PNG で保存。コマを選び直せばそのコマが落ちる |
| SAVE VIDEO | 録れているときだけ出る |
| CLOSE | 閉じる |

左右キーでコマの時間を選べます（上下でコマ選びとボタン選びを行き来）。

## タイトル画面

ロゴ → アイテム一覧 → ハイスコア → HISCORE(HARD) → ボスラッシュのタイム、の
5 画面が順に入れ替わります(**左右キー**でも送れます。端では回り込みます)。
モードを選べるのは**ロゴの画面だけ**で、**上下キー**で選び SPACE で開始します。
ほかの 4 画面では `SPACE TO TITLE` と出て、SPACE でロゴへ戻ります
(一覧の画面では上下がスクロールなので、モード選びとぶつからないようにしてあります)。
ロゴの「STAR」と「FABLE」のまわりを、それぞれ光がぐるぐる回ります。

難易度は **通常** と **HARD** の 2 つです。ゲーム中では HARD だけを名前で呼び、
通常のほうは「NORMAL」と名乗りません(モード名も `GAME START`)。

| モード | 内容 |
|---|---|
| GAME START | 通常のゲーム(既定)。下の表のとおり全面的にやさしい |
| HARD GAME | 装備が下がり、敵の手数も多い歯ごたえのあるほう。**別のランキング**に載る |
| BOSS RUSH | 1〜4 面のボスをランダムな順で 1 巡(ラスボスと仮ボスは入らない)。背景の賑やかしは出ない。タイムを競う |
| STAFF ROLL | 役職付きのスタッフロール(裏技のヒントを兼ねる)。背景は星座「くじら」 |
| SOUND TEST | 左が BGM、右が SE / ジングル。左右で列、上下で曲を選び SPACE で再生。止めるのは一覧の `- STOP -` |
| CHARACTERS | 敵・ボス・背景パーツの図鑑(左右でページ送り、SPACE で次へ。右上に `3/22` のページ番号)。ラスボスは出会うまで `?`。**最後のページ (ALL STAR)** は敵・自機・弾を 40 枚以上いっぺんに出す、ちらつきの見物用 |
| ABOUT MMSXX ENGINE | エンジンの紹介。エンディングと同じストーリー画面で 3 枚見せる |

## 画面構成

画面のまわりに **8 ドットのボーダー**を持たせています(実際に出るのは 272x208)。
ここには何も描かれず背景色で塗られ、**被弾したときに画面全体を 1 ドット単位でずらして
揺らす**ための余白になっています(実機の `SET ADJUST` 相当)。
揺れの大きさは バリア/被弾 < クリティカル < 撃墜 の順に大きくなります。


5 レイヤーの 8 ドット単位・視差付き縦スクロールです(裏画面 256x1024)。

| レイヤー | 内容 | スクロール速度 |
|---|---|---|
| 0 | 遠い星 | 0.25 |
| 1 | 中間の星 | 0.9 |
| 2 | 近い星 | 2.0 |
| 3 | 大きな背景オブジェクト / ボス | 0.25(ボス戦では専用) |
| 4 | HUD | 固定 |

BG スプライトはレイヤーと同じ優先度空間を使うので、この合間に差し込めます。
流れ星は `priority = 2`(近い星の手前・大きな背景オブジェクトの奥)、
敵やボスは `priority = 3` 以上です。

大きな背景オブジェクト(ステーション・月・木星・土星・コロニー・モアイ・地球・
ブラックホール・星雲・デブリ・天の川)は、手前の星に隠されないよう星より前のレイヤーに置き、
速度だけ最背面と同じにして遠くに見せています。面ごとにランダムで 3 種類を選びます。

## 進行

- **宝珠(ORB)を集めるとボス戦**。必要数は面が進むごとに増えます(最大 6)
- 宝珠がそろうと、しばらく敵が出なくなり、BGM がフェードアウトしてから
  ボス名が表示され、ボスが登場します
- ボスを倒すと自機がいったん画面上へ飛び去り、次の面が始まります(**全 5 面**)
- **5 面(FINAL STAGE)はラスボス専用の面**です。宝珠を集める必要はなく、敵もアイテムも出ません
  1. はじめの **10 秒は何も出ません**。背景の大きな絵も出ず、星だけの静かな宇宙が流れます
  2. そのあと**木星**が画面の上から入ってきて、ゆっくり降りていきます
  3. 木星が流れ切るころ、ボス登場の演出に入ります
  - 木星は**この面にしか出てきません**。**大赤斑のあたりに撃てる 16x16 の隠し場所**があり、
    **16 発当てると全パワーアップ**が手に入ります(自機はぶつかりません)
- ステージ開始から **キューブは 4 秒・その他の敵は 8 秒**出ません
- 面の始めに、開始ジングルに合わせて `STAGE n` を出します

### 通常モード(既定)

見た目や装備をゆっくり楽しむためのモードです。HARD とは**別のランキング**に載ります。
下の表は HARD との違いです。

| 項目 | 内容 |
|---|---|
| 初期装備 | ボスラッシュと同じ(ショット 3 段階・スピード 2・連射 2・パワー 2・バリア 1) |
| 装備の低下 | **バリア以外は下がらない**。やられても装備はそのまま |
| 出てこない敵 | 左右から挟み込む UFO、下から来る敵 |
| 小惑星 | 同時に 1 つだけ |
| 黄色いキューブ | よく出る(連射中は出ない) |
| 集める宝珠 | 5 個まで |
| 敵弾 | 間隔が倍 = 数が半分 |
| 残機 | 5 |

### そのほかの出現ルール

- **下から来る敵**は、1 面と「後ろに撃てないうち(ショット 3 段階未満)」は出ません
- **目玉と小惑星は排他**。どちらかが出ているあいだ、もう一方は出ません
- **中ボスのモアイ**が出ているあいだは、敵もアイテムも出ず、曲も専用のものに変わります。
  出てきた瞬間に、飛んでいる敵は**キューブも含めて全部**片づきます

### 合体モアイの流れ

| 段階 | 見た目 | 手出し |
|---|---|---|
| 四隅からせり出す(構え中) | **白＋灰の石** | **弾も自機もすり抜ける** |
| 四隅(構え終わり〜左右合体) | **白＋灰の石** | 自機は当たる。弾ははじかれ、撃ち込み続けると怒る |
| 左右合体 → 2〜5 秒の待ち | **白＋灰の石**（終わりぎわに一瞬光る） | 同上。ただし**撃ち込み続けると怒る** |
| 色が付く（緑⇄青） | 色つき | ここから戦える。`BREAK IT FROM INSIDE!` が出る |
| 上下が寄る（5 秒） | 色つき | **内側の切り口**を撃つとダメージ。外側は弾かれる |
| 上下合体（1 体） | 色つき + 縞 | どこでも効くが硬い。30 秒で赤くなって下へ去る |

**怒らせると**赤とピンクに変わり、二度とこわせません。リング弾が 1.5 倍速になり、
30 秒で下へ流れ去ります。石のあいだ（内側でも外側でも）に撃ち込みすぎるか、
色が付いてから**外側**を 12 発撫でると怒ります。手を出さずに待つのが正解です。
- 背景には**流れ星**がときどき流れます(当たり判定なし)。
  大きな背景オブジェクトより**奥**に置いてあるので、木星などに重なっても手前に出ません

## 自機とアイテム

ショットは 8 段階です。

| Lv | 前 | 後ろ |
|---|---|---|
| 1 | 1 発 | — |
| 2 | 2 発(平行) | — |
| 3 | 2 発(平行) | 1 発 |
| 4 | 3WAY 狭 | 1 発 |
| 5 | 3WAY 狭 | 2 発 V 狭 |
| 6 | 4WAY 広 | 2 発 V 狭 |
| 7 | 5WAY 広 | 2 発 V 狭 |
| 8 | 5WAY 広 | 3 発 広 |

| アイテム | 効果 |
|---|---|
| WIDE SHOT | ショットの段階を上げる(最大で取るとボムになる) |
| ORB | 集めるとボス戦へ |
| BOMB | 画面上の敵と敵弾を全滅 |
| SPEED UP | 移動速度(3 段階) |
| RAPID FIRE | 画面に出せる弾数(1 → 4) |
| POWER SHOT | 弾の威力(3 段階) |
| BARRIER | 被弾の身代わり(最大 8) |
| 1UP | 残機 +1 |
| `?` | しばらくオート連射(押しっぱなしの間隔が短くなる) |
| `$` | スコア。続けて取ると 100 点から倍々で 102400 点まで上がる(取るとファンファーレが鳴り、次はまた 100 点)。取りこぼすかミスすると連鎖は切れる |

アイテムの種類は**スコアの 100 の位**(+小さな乱数)で決まります。
0 のときだけランダム枠で、1UP・`$`・`?` はここからしか出ません。
すでに上限で意味のないものが選ばれた場合は、まだ有効なものから選び直し、
全部そろっていればボムになります。

被弾するとバリア → ショットのダウンの順で身代わりになり、1way で被弾すると 1 機失います。
ミス後は画面下からせり上がって復帰し、**残り 1 機になると警告音とメッセージ**が出ます。

## ボス

ボスは BG レイヤーに描き、レイヤーのスクロールで動かします。
どのボスも**装甲(乗り物・甲羅)を壊すと攻撃能力が落ちる**ので、
近づいて連射で攻略できます。

ボスは **4 体 + ラスボス**です(BIG MOAI はボスではなく、道中に出てくる大きい敵)。

- **1 面 KING OCTOPOT**
  弾のほか、停止 → 溜め → 黄色い極太レーザーを撃ちます(触れると即死)。
  8 割のダメージで船が壊れ、頭部ユニットだけになります
- **2 面 KING FOSSIL**
  左右の壁を足場に上下へ動き、大きなハサミを 2 発撃つと手が無くなります。
  撃ち尽くすと反対の壁へ跳んで移動し(この間は無攻撃)、着地するとハサミが再生します。
  甲羅がはがれるとひっくり返り、泡を吹くだけになります

### ボスの設計方針

どのボスも次の考え方で作る。

1. **弱点がある**。当てると大ダメージ(3 倍)で、正面から削るより早く倒せる
   - 弱点かどうかは**音で分かる**(弱点 = 高く抜ける `weak` 音 / 装甲 = 低く重い `armor` 音)
   - 弱点に当たると**スプライトの光**が出るので、目でも分かる
2. **いくつかのパーツでできていて、部位破壊ができる**
   (タコは乗っている船、カニはハサミと甲羅、ドラゴンは装甲)
3. **無防備な状態になる**と、撃ってくる弾は撃ち落とせるものだけになり、
   強引な連射でも攻略できるようになる
   - タコ: 船が壊れて頭部だけになる / カニ: 甲羅がはがれてひっくり返る
4. **早く倒すほど高得点**。撃破タイムで 4 段階に分ける

| ランク | 撃破タイム | ボーナス |
|---|---|---|
| S | 15 秒以内 | 200,000 |
| A | 30 秒以内 | 100,000 |
| B | 45 秒以内 | 50,000 |
| C | それ以上 | 0 |

ボーナスは面数によらない固定額です。

### 面の評価

ボスを倒すと、その面のまとめが出る。

- `RANK` と撃破タイム
- `BOSS BONUS` … 上のランクごとの固定ボーナス
- `BIG ENEMY` … 目玉・小惑星・ロケット弾など大きい敵を倒した数 x 2000
- `$ CHAIN` … その面で伸ばした $ の最高額 x 10
- `TOTAL` … 合計

## 未実装さん(Mr. MIJISSOU)

本編には出てこない相手ですが、**2 回目のコンティニュー**のときだけ、
面のはじめに顔を出します(1 ゲームに 1 回。一度会えばもう出てきません)。
倒しても見逃しても面はクリアにならず、そのままコンティニュー先の面が始まります。

体力は **1000 で固定**。ボスラッシュ / シーン選択 / コンティニューの
どこから出会っても同じ手ごたえです。

**この相手からダメージを受けることはありません。**
攻撃してこないうえ、体当たりも涙も無害です。

### 話しかけてくる

- 体力が **半分**を切ると、ふきだし(中は「…」)で話しかけてきます。
  意味は**画面の真ん中に英語**で出ます(画面幅を超える文は 2 行に折り返し)
- ふきだしは顔の右横。話しているあいだは出しっぱなしで、英文だけ入れ替わります
- 話しているあいだも**ふつうに動けて撃てます**。本人は動きません
- 話し始めに飛んでいた自弾は消えます(連射のまま読み飛ばさないように)

### 3 つの終わりかた

| どうしたか | 結果 |
|---|---|
| 話し終わりに体力が **2 割より多く**残っている | いいことを教えて**飴を 10 個**置いて帰る |
| 削りすぎていた | 黙って戦いに戻る(見逃したことにはならない) |
| 話し始めてから **16 発**撃ち込む | `SO SAD...` と言って**自爆**する |
| 倒し切る | `THAT IS CRUEL...` と言って涙の海で爆発 |

### 教えてくれる「いいこと」

**コンティニューで出会ったときは裏技のヒントで固定**。
ボスラッシュ / シーン選択から戦ったときは、8 つからその場で選ばれます。

1. スタッフロールの名前は、ポーズ中に打てるコマンド名
2. 星のりゅうの顔には秘密がある
3. 嫌いなものは好きなものと一緒に食べるとよい
4. 大人になると涙もろくなる
5. サンタクロースはいない
6. 納豆はかき混ぜてから醤油
7. お母さんとお父さんはもともと他人
8. 血液型で性格は変わらない

どれを教えたあとも `WAS THAT USEFUL?` と言います。

### 飴(キャンディ)

- **10 個**を四方へゆっくり散らします(4 秒かけて広がり、そのあと落ちてくる)
- 水色とピンクを **2 コマずつ**入れ替えて光ります
- 得点は取るたびに倍。**100 / 200 / 400 / … / 51200** で、
  10 個そろえると飴だけで **102300 点**(アイテム共通の 500 点 x 10 を足すと 107300 点)
- 全部拾うとファンファーレと `ALL CANDIES!  THANK YOU!`
- 拾う時間は **11 秒**。そのあいだ本人はゆっくり上へ帰っていきます

- 図鑑では、会うまで**姿も名前も伏せて** `?` と `???` になります

## ハイスコア

- 100 位まで localStorage に記録します
- タイトルでは 7 人ずつ表示します。ふだんの画面送りでは **TOP から動かしません**。
  上下キーで自分でたどれます
- **名前を登録した直後だけ**、そのランキングの一覧へ移り、
  **自分の順位が上下の真ん中**に来る位置から始まります
- ゲームオーバー時に名前を 5 文字まで入力できます
  (ESC で登録せずに抜けられます。前回の名前が初期値です)
- 入力は **2 通りとも使えます**。キーボードで打ち込むか、
  **左右キーで桁を選び、上下キーで文字を送る**か。▲が付いている桁がいま選んでいる桁です

## エンディング

全 6 面をクリアすると、**4 秒 x 3 枚 = 12 秒**のエンディングが流れます。
絵を見せながら、画面の下に文章が 1 文字ずつ出ます。**スタッフロールへは行きません**
(スタッフロールはタイトルのモードとして別に見られます)。

| # | 絵 | 文章 |
|---|---|---|
| 1 | 地球と、帰っていく自機 | PEACE RETURNED / TO THE STARS. |
| 2 | 天の川と土星 | CONGRATULATIONS! / THANK YOU FOR PLAYING! |
| 3 | 青い裂け目にひそむ影(背景は紺) | A SHADOW LURKS IN THE RIFT. / TO BE CONTINUED? |

> ボスが青い裂け目へ逃げていくところは、**エンディングではなく撃破の演出**で見せる（これから）。

曲はエルガー「愛の挨拶」。見終わると得点の登録へ進みます。SPACE で先送り、ESC で飛ばせます。
中身はエンジンの任意部品 [`StoryScenes`](UTIL.md) にまかせているので、
場面を足すのは配列に 1 つ書き足すだけです。

## 裏技(ポーズ中)

`↑↑↓↓←→←→BA` 以外は、文字を打ってから **RETURN** で確定します。

`Q` だけは裏技ではなく**普通の操作**で、ポーズ画面に案内が出ています。
ほかの語と違い**ちょうど `Q` のときだけ**効きます（`AAAAQ` では戻りません）。

| 入力 | 効果 | 回数 |
|---|---|---|
| **Q** | **タイトルへ戻る**（コンティニューは消える。裏技ではない） | 制限なし |
| ↑↑↓↓←→←→BA | 全パワーアップ | 1 ゲーム 1 回 |
| HYPER | 同上 | 1 ゲーム 1 回 |
| MEIJIN / TAKAHASHI / TOSHIYUKI | オート連射 | 3 つ合わせて 1 ゲーム 3 回 |
| AHO / BAKA | 自爆 | 制限なし |
| MOMOKO / CHIE / AKEMI / SYUKO / CHIAKI | 1〜5 面へワープ(**得点が 0 に戻る**) | 制限なし |
| NORIKO / SATOE / YASUKO / KINUYO / HISAE | 1〜5 面のボスと直接対決(練習モード。倒すと同じボスがまた出る。**得点が 0 に戻る**) | 制限なし |
| MIYUKI | 仮ボス「未実装君」と対決(本編には出てこない。**得点が 0 に戻る**) | 制限なし |
| YOHKO | エンディングを見る | 制限なし |
| AHOAHO / BAKABON | 一気にゲームオーバー(残機ごと捨てる) | 制限なし |
| ORB | 宝珠を満タンにする(開発中だけ) | 制限なし |
| DRAGONFIRE | 七色の推進炎を手に入れる(開発中だけ。5 面以降) | 制限なし |

## URL で変えられること

遊ぶ人が触ってよいものだけ、URL の後ろに付けて変えられます。
おかしな値は黙って既定に戻ります。

```
?scale=2          画面の拡大率（1〜8。既定 3）
?palette=rf       色合い（tms9918 / toshiba / rf / v9938）
?linesprites=4    1 行に出せるスプライトの数（0 = 無制限。既定 4）
?maxsprites=32    画面ぜんぶで出せる数（0 = 無制限。既定 32）
?rotate=stride    消える順の回しかた（step / stride / random / slow / off）
?slow=24          この数を超えたら処理落ち（既定 0 = しない）
?mute=1           音を消して始める
?volume=70        音の大きさ（0〜100）
?mode=hard        始めかた（normal / hard / bossrush / staff / sound / chars）
```

**開発版だけ効くもの**（公開版は URL に何を書いても無視します）。

```
?fps=30           1 秒あたりのコマ数（難しさを下げる道具にされないため）
?stage=3          その面から始める
?seed=12345       乱数の種を決める
?invincible=1     やられない
```
