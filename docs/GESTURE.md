# ジェスチャの見分け（engine/util/gesture.js）

指の動きに「タップ」「スワイプ」「フリック」などの**名前を付けて知らせるだけ**の部品。
ゲームがメニューの操作をこれに乗せるための口をまとめてある。

- 実装: [`engine/util/gesture.js`](../engine/util/gesture.js)
- 確かめる器: [`tools/gesture-tool/`](../tools/gesture-tool/index.html)
  （開発版で `https://dev.msxpoi1.pages.dev/tools/gesture-tool/`。**まだ詰めていない**）

**この部品は何も決めない。** 「左フリックで次のページ」といった割り当ては、
受け取った側（ゲーム）が決める。エンジンは名前を付けるところまで。

---

## 0. いま要るのはこれだけ

**指のイベントを拾って返す、それだけの口。** 使うのは次の 8 つ。

| | 上 | 下 | 左 | 右 |
|---|---|---|---|---|
| **フリック**（払う。1 回だけ）| `flick` `dir:'up'` | `'down'` | `'left'` | `'right'` |
| **スワイプ**（引きずる。続けて）| `swipe` `dir:'up'` | `'down'` | `'left'` | `'right'` |

`tap` / `longpress` / `pinch` / `down` / `up` も出るが、**いまは使わない**。
消していないのは、動いていて試験も通っているぶんを捨てる理由が無いため。
邪魔なら見なければよい。

### PC の割り当ては別途

キー操作をジェスチャに寄せて、**PC でもすべてジェスチャとして扱う**案がある。

- フリック … キーを押したのと同じでよさそう
- スクロール … 小さなスワイプを続けて送る感じ

**まだ決めていない。** いまはスマホのイベントをそのまま流すところまで。
PC は今までどおり `Input`（矢印キー）が受け持つ。

## 1. 使いかた

```js
import { createGesture } from './engine/util/gesture.js';

const g = createGesture({
  el: document.getElementById('menu-layer'),   // 指を受ける要素
  onGesture: (e) => {
    if (e.type === 'flick' && e.dir === 'left') nextPage();
    if (e.type === 'swipe') scrollBy(-e.dy);
    if (e.type === 'tap') select(e.x, e.y);
  },
});

g.setOptions({ flickMinSpeed: 0.7 });   // いつでも変えられる
g.detach();                              // 外す
```

`el` に渡した要素の中だけを見る。**エリアの取りかたは渡す側が決める**
（`engine/util/touch.js` と同じ考えかた）。

## 2. 出てくるもの

`onGesture(e)` に、次のどれかの `e` が渡る。

| `e.type` | いつ出るか | 添えて出るもの |
|---|---|---|
| `down` | 最初の指が触れた | `x` `y` |
| `tap` | 短く触れて離した | `x` `y` `ms` |
| `longpress` | 動かさずに押し続けた | `x` `y` |
| `swipe` | 動いているあいだ**続けて** | `x` `y` `dx` `dy` `totalX` `totalY` `dir` |
| `pinch` | 指 2 本以上の間隔が変わった | `scale` `spread` `x` `y` |
| `flick` | 離した瞬間、速く払っていたら**1 回だけ** | `x` `y` `dx` `dy` `ms` `speed` `dir` |
| `up` | 最後の指が離れた | `x` `y` `dx` `dy` `ms` `speed` |

どれにも共通で付くもの。

| 名前 | 中身 |
|---|---|
| `type` | 上の表の名前 |
| `fingers` | そのひとまとまりで使われた**最大の指の本数** |
| `source` | `'touch'` / `'mouse'` / `'pen'` |
| `t` | `performance.now()` の時刻 |

- `x` / `y` は**指の重心**（2 本なら真ん中）。画面の座標
- `dx` / `dy` は前回からの差、`totalX` / `totalY` は触れはじめてからの差
- `dir` は `'left'` / `'right'` / `'up'` / `'down'` の 4 方向
- `scale` は触れはじめの間隔に対する倍率（1 より大きければ広がった）

### スワイプとフリックは別のもの

|  | 出かた | 何に使うか |
|---|---|---|
| **スワイプ** | 動いているあいだ**続けて** | 一覧の送り。指に付いてくるもの |
| **フリック** | 離した瞬間に**1 回だけ** | ページのめくり。連続しないもの |

**1 回の操作で両方出ることがある**（送りながら最後に払う）。どちらを見るかは使う側が決める。
この使い分けは [SMARTPHONE.md](SMARTPHONE.md) と [TODO.md](TODO.md) の J 章の
「上下スクロール・左右ページ」に合わせてある。

`tap` と `flick` は同時には出ない（短く止まって離せば `tap`、払えば `flick`）。
`up` はどちらの場合も最後に出る。

### ピンチのあいだは swipe も flick も tap も出ない

指を広げると重心がぶれるので、そのままだと**動かしていないのにスワイプ**が出る。
手早く広げると**タップとも見分けが付かない**。なので、いちど `pinch` が出たら、
そのひとまとまりでは `swipe` / `flick` / `tap` を出さないようにしてある。

**指 2 本をそろえて動かしたぶん（間隔が変わらない）は、今までどおり `swipe`。**
2 本指スワイプと 3 本指スワイプは `fingers` で見分ける。

### 指が増えたら基準を取り直す

重心も指の間隔も、指を足した瞬間に飛ぶ。取り直さないと、**2 本目を置いただけで
「横へ払った」「広げた」ことになる**。`x0` / `y0` / `spread0` を置き直している。

## 3. しきい値

`createGesture()` に渡すか、`setOptions()` でいつでも変えられる。

| 名前 | 既定 | 何を決めるか |
|---|---|---|
| `tapMaxMs` | 250 | これ以内に離せばタップ（ms）|
| `tapMaxDist` | 10 | これ以上動いたらタップにしない（px）|
| `longPressMs` | 500 | 押し続けてこれだけ経ったら longpress（ms）。**0 で出さない** |
| `swipeMinDist` | 12 | これだけ動いたらスワイプが出はじめる（px）|
| `flickMinSpeed` | 0.5 | 離すときのこの速さ以上でフリック（px/ms）|
| `flickWindowMs` | 120 | 最後のこれだけの間の動きで速さを測る（ms）|
| `pinchMinScale` | 0.05 | 間隔がこの割合ずれたらピンチ |

**まだ実機で詰めていない。** `tools/gesture-tool/` で触って決める。

## 4. PC ではどうなるか

**偽のジェスチャは作らない。** pointer のイベントを見て名前を付けるだけなので、
実機では指の動きが、PC ではマウスの動きが、そのまま同じ形で出てくる。

- マウスは**指 1 本ぶん**。`tap` / `longpress` / `swipe` / `flick` は出る
- **`pinch` と 3 本指は PC では出ない**（指が足りないため）
- どちらから来たかは `source` で分かる

**PC で困らない。** 一覧の送りやページのめくりは、もともと矢印キーが受け持っている
（`Input` のほう）。ジェスチャは**指のときだけの足し**と考えればよい。

一度マウスで偽の多点タッチを作る案（Shift で 2 本指など）を入れたが、
矢印キーで足りるので**やめた**。仕組みを二重に持たないほうが読みやすい。

## 5. 気をつけること

- **`pointercancel` も拾っている**（着信やジェスチャで指が消えることがある）
- 指が要素から滑り出ても、`setPointerCapture()` で続きが届く。
  **捕まえられなくても先へ進む**（例外で `pointerdown` の残りが飛ぶため）
- `contextmenu` は断っている（長押しメニュー対策）
- **ページのスクロールを止めるのは、この部品の仕事ではない。**
  渡す要素に `touch-action: none` を当てるなどは、載せる側でやる。
  やりかたは [SMARTPHONE.md](SMARTPHONE.md) の 8 節
- **3 本指のジェスチャは iOS では取りこぼす。** OS の「ズーム」（設定 →
  アクセシビリティ）が先に取ってしまう。使うなら**誤動作する前提**で、
  それ 1 つでしか行けない操作は割り当てない
