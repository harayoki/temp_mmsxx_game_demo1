# フォントデータ作成ツール — いったん中断

> **開発中断中。** ここまで作ったものは動くが、**再開するときに仕様が変わる。**
>
> 理由: オリジナルのフォントを起こすつもりだったが、**外部フォントを入れてみたら
> それで十分だった**ため。フォント全体を変換する必要がなくなり、
> **これから先は絵文字・特殊文字(外字)だけを扱えばよい**見込み。
>
> 下の「7. 再開するときに変わるところ」を先に読むこと。

- ツール本体: [tools/font-tool/](../tools/font-tool/)
  (`index.html` / `font-tool.js` / `style.css`)
- 開きかた: `node serve.js` して `http://localhost:8080/tools/font-tool/`
- 画面の名前: **MMSXXフォントデータ作成ツール**

元にした指示書は「MSX風フォント変換ツール 指示書(フォントデータ書き出し機能)」
(PDF、リポジトリ外)。以下はそれに対して**実際に何を作ったか**の記録。

---

## 1. できること

PC / Web のフォントから、ビットマップフォント(JSON + インデックス PNG)を書き出す。
指示書の進めかた 1〜4 まで。

**1. フォント読み込み**

- PC に入っているフォントの一覧(Local Font Access API)
- 「日本語が入っているものだけ」で絞り込み。
  かな・漢字を実際に描いて、代替フォントの絵と違うかで判定する
- フォントファイルの読み込み(`.ttf` / `.otf` / `.woff` / `.woff2`)
- フォント名の直接指定(`MS Gothic` など)
- フォントの置き場所の案内(コピーボタン付き)。
  自分で足した場所は `localStorage` に覚える

**2. 文字範囲**

- プリセット 7 種(半角英数記号 / 半角カナ / 全角ひらがな / 全角カタカナ /
  全角記号・約物 / 全角英数記号 / 漢字すべて)
- 追加したい文字をそのまま書く欄
- コードポイント範囲の欄(`3005 4E00-4E10` のように 16 進で)

**3. ラスタライズ**

- 黒背景・白文字。しきい値で 1 ビットに落とす
- グリフの大きさ(既定 12x12)、描画サイズ、縦横のずらし
- **枠からはみ出たら形のまま縮める**(既定 ON)。
  文字送りではなく**実際に墨の乗る範囲**で測り、縦横とも枠に収まるまで
  等倍で縮めて、上下も枠内へ押し戻す
- **半角は横半分の幅**(既定 ON)。幅は `floor(グリフ幅 / 2)`(12 → 6、端数切り捨て)。
  対象は `0x20-0x7E` / `0xFF61-0xFF9F` / `0xFFE8-0xFFEE`。
  決めた幅から先は、にじみも含めて捨てる
- 縦の余りドットの寄せかた(上 / 下 / 上下均等)。
  これは JSON に書くだけで、絵そのものは変えない
- フォントに無い字は `codes` に入れず、飛ばした字を画面に出す

**4. アトラス生成 + 書き出し**

- JSON + インデックス PNG の 2 ファイル
- プレビュー(拡大 1x / 2x / 3x / 4x)
- **書き出したときの大きさを線で出す**チェック。
  橙 = グリフそのもの、青 = 1 文字が食う場所(12x12 なら 12x16)。
  寄せかたが線に反映され、線は拡大しても太さ 1 ピクセルのまま

---

## 2. 出力の形

```json
{
  "format": "mfont1",
  "kind": "font",
  "glyphSize": { "w": 12, "h": 12 },
  "atlasCols": 16,
  "atlas": "msxfont.png",
  "verticalPad": "center",
  "codes": [32, 33, 34, 12354, 12356],
  "widths": [6, 6, 6, 12, 12]
}
```

- `codes` の**添字 = アトラス内の並び順**。値は Unicode コードポイント。
  座標は持たせず
  `x = (index % atlasCols) * glyphW`, `y = floor(index / atlasCols) * glyphH`
  で求める
- `widths` は**指示書に無い、あとから足したもの**。codes と同じ並びで、
  その字が横に何ドット食うか。全角 = 12、半角 = 6。
  **アトラスの枠は全部おなじ大きさのまま**にして(並び順から座標を出す計算を
  崩さないため)、半角は枠の左半分に描いてある
- `verticalPad` は余りドットの寄せかた。`top` = 余りが上(字は下に付く)
- PNG は **1 ビット・2 色パレットのインデックス PNG**。自前で組んでいる
  (CRC32 / Adler32 / チャンク / zlib)。`CompressionStream` があれば圧縮、
  無ければ無圧縮ブロックで包む

---

## 3. 確認したこと

`MS Gothic` を名前指定して、ブラウザ上で実測した結果。

- 半角英数 + ひらがな + カタカナ = 286 文字、アトラス 192x216
- 書き出した PNG をデコードし直して元のドットと突き合わせ → **不一致 0**
  (2.7KB)
- 8x8 / 12x12 / わざと大きい 12x12+22px のどれでも、**枠外へのはみ出し 0 ドット**
- 余りドットの寄せかたを変えると、プレビューの枠が 4 / 0 / 2 ドット動く
- 線の太さは 1x / 2x / 3x / 4x のどれでも 1 ピクセル

## 5. 中断した時点でのやり残し

仕様が変わる前に片づけておくべきだったこと。**4 節(作っていない機能)とは別に、
「作ったけれど確かめていない」ものがここにある。**

**確かめていないこと**

- **PC のフォント一覧が、一度も出せていない。**
  作業した環境は `local-fonts` の許可が `denied` で、実際に一覧が並んだところを
  見ていない。**動作確認はすべて「フォント名を直接指定」(`MS Gothic`)で行った。**
  一覧まわり(絞り込み・選択・エラーの出し分け)は、実ブラウザでの確認が要る
- **コピーボタンが本当にクリップボードへ入るか。**
  スクリプトからの疑似クリックでは権限が下りず、
  取れなかったときのフォールバック表示までしか見ていない
- **画面の見た目そのもの。** ブラウザの表示枠が出せず、
  DOM と数値だけで確かめている。並びや大きさは目で見ていない
- **漢字すべて(約 2 万字)での実測。** 重いという前提のままで、
  かかる時間もアトラスの大きさも測っていない

**決めていないこと**

- **`widths` を読む側が無い。** 半角を横半分にするために独自に足したが、
  エンジン側は未対応。**指示書の「1 データ = 1 サイズ」から外れる拡張**なので、
  読む側の仕様ごと決め直す余地がある
- `.ttc` は非対応のまま(読めない旨を出すだけ)
- 常用漢字のプリセットは無く、コードポイント範囲での代用のまま

**確かめてあること**(念のため)

書き出し(`exportFiles`)は、ダウンロードを差し替えて経路ごと通してある。
`msxfont.png`(2749B) と `msxfont.json`(2363B)が出て、
`codes` / `widths` とも 286 件そろう。

## 6. 気をつけること

**フォント一覧が出ないとき。**
Local Font Access API は**ページごとの許可**がいる。許可がブロックされていると
ダイアログも出ずに失敗する。アプリの中のブラウザやプレビュー枠では
そもそもダイアログを出せない(確認したときは `local-fonts` の状態が `denied`
だった)。ツール側は理由を判定して書き分ける
(`denied` / `prompt` / `granted` なのに 0 件)ようにしてあるので、
**Chrome か Edge のふつうのウィンドウで開き直す**のが確実。
一覧が使えなくても「ファイルから読む」「名前を直接指定」は動く。

**`.ttc` は読めないことが多い。**
Windows の `msgothic.ttc` のように何書体か束ねたファイルは、ブラウザでは開けない。

**フォントに無い字の見分けかたは当て推量。**
ブラウザは無い字を勝手に別のフォントで描いてしまうので、
「実在しないフォント名」で描いた絵と見くらべている。
にじみを丸める前の画素で見ることで取りこぼしは減らしたが、確実ではない。

## 7. 再開するときに変わるところ

**フォントを丸ごと変換する必要はなくなった。** 外部フォントをそのまま使う。
これから要るのは**絵文字・特殊文字(外字)の扱いだけ**。

つまり、次に手を付けるときの見直し先はこのあたり:

- **文字範囲のプリセットは要らなくなる**(2 節)。
  代わりに「この字だけ」を並べる作りになる
- **外字の番号の決めかた**が要る。Unicode の私用領域に載せるのか、
  別の番号を振るのか。指示書では外字/アイコン登録は**対象外**だったので、
  ここは決めごとから
- 出力の形(`mfont1`)を**そのまま使うのか、外字用に分けるのか**。
  `kind` を `"font"` 以外にして分ける余地は残してある
- 本体のフォントと**同居させるのか、別ファイルにするのか**
  (指示書でも「フォントと同居させる仕様は別途検討」となっていた)
- 絵文字はフルカラーが要るかもしれない。いまは 1 ビット 2 色のみ

**いまのコードで使い回せそうなところ:**
ラスタライズ(はみ出し詰め・しきい値)、アトラス生成、インデックス PNG の
書き出し、プレビューの線。ここは対象が全文字でも数文字でも変わらない。
