# MMSXX Engine ドキュメント

MSX1(TMS9918)風の見た目と音を再現するブラウザ用ゲームエンジンです。
GUI ツールは無く、**ゲームデータをコードで書く**スタイルで作ります。

## 画面のしくみ

- 表示画面は既定 **256x192**。**8 ドット単位で増減**できます(`setScreenSize`)
- その外に**ボーダー**を置けます(`setBorder`)。何も描かれず、いつも背景色です
- **画面全体を 1 ドット単位でずらせます**(`setAdjust`。実機の SET ADJUST 相当)。
  ずらしたぶん反対側から回り込むことはなく、空いたところは背景色になります。
  画面をぶるっと揺らす演出に使えます
- 裏画面(仮想画面)は **256〜2048 の 2 の冪**で指定します
- 裏画面はレイヤーごとに別の大きさを持てます。**枚数に上限はありません**
- 各レイヤーは独立したスクロール位置を持ち、上下左右にリピート(ラップ)します

```js
import { MMSXXEngine } from './engine/engine.js';

const mmsxx = new MMSXXEngine(canvas, {
  scale: 3,
  virtualWidth: 256, virtualHeight: 1024,   // 既定サイズ
  layers: [{}, {}, {}, {}, {}],             // 5 枚。{width,height} で個別指定も可
});
```

描画の重なりは奥から
**背景色 → レイヤーと BG スプライト → 通常スプライト** の順です。

**レイヤーと BG スプライトは同じ優先度空間**を使います。
BG スプライトの `priority = n` は「**レイヤー n の手前**」という意味で、
レイヤーの合間に差し込めます(`n` が負なら全部のレイヤーより奥)。
たとえば「星より手前、大きな背景オブジェクトより奥」に置きたい流れ星は
`priority = 2` にします。

## 色の制約

RGBA 画像を書き込むと、自動で MSX1 の制約へ変換されます(結果はキャッシュされます)。

- MSX1 の 15 色パレットへ量子化(パレット 0 は透明)
- SCREEN2 と同じ **「横 8 ドットにつき 2 色まで」**。
  絵を重ねて描いても、書き込みのたびに制約へ戻します
- レイヤーに描くと、**8x8 セル内に色 2 以上のパターンがあるセルの透明(0)は黒(1)** になります
  (「キャラパターンのあるセルは不透明」という実機 BG の見え方)
- BG スプライトも同じ規則で 8x8 セルを黒く埋めてから描かれます
- スプライト用に「画像全体で N 色まで」の変換モードがあります
  - `{ colors: 1 }` = 実機の単色スプライト
  - `{ colors: 2 }` = スプライト 2 枚重ね風
  - こちらは透明をそのまま保つので、穴あきスプライトが作れます

8 ドットの境界は「画像自身の x=0 起点」です。レイヤーに描くときに x を 8 の倍数へ
置くと、実機の SCREEN2 と同じ見え方になります。

## API

```js
// ---- 画面 ----
mmsxx.backdrop = 4;                    // 背景色 (パレット番号 1..15)
mmsxx.screenWidth; mmsxx.screenHeight;   // 描画領域(既定 256x192)
mmsxx.setScreenSize(240, 176);         // 8 ドット単位で増減できる
mmsxx.setBorder(16, 8);                // ボーダー(描画領域の外の遊び)の厚み
mmsxx.outWidth; mmsxx.outHeight;         // ボーダー込みで実際に出ている大きさ
mmsxx.setAdjust(-2, 1);                // 画面全体を 1 ドットずらす(-15..+16)
                                     // 回り込まず、空いたところは背景色になる
// ---- 画面のキャプチャ ----
// 実描画そのものが原寸のオフスクリーンなので、原寸の取り出しがいちばん安い
mmsxx.capture();                       // data URL (image/png)
mmsxx.capture({ type: 'blob' });       // Promise<Blob>
mmsxx.capture({ type: 'canvas' });     // canvas(複製)
mmsxx.download('shot.png');            // そのまま保存
mmsxx.layerCount;                      // レイヤー枚数
mmsxx.isLocal;                         // 手元の開発中か(localhost / file:)
                                     // デバッグ機能の出し分けに使う

// ---- エラーログ ----
// 日付ごとに 1 つ、3 日ぶんだけ残す(起動時に古いものを消す)。
// 手元の開発中はエラーでそのまま止め、公開版は致命的でなければ続ける。
mmsxx.errors.log('なにか変');           // 自分で 1 件記録する
mmsxx.errors.log('致命的', { fatal: true });
mmsxx.errors.read();                   // 今日のログを読む
mmsxx.errors.days();                   // 残っている日付(新しい順)
mmsxx.errors.clear();                  // 全部消す
mmsxx.virtualWidth; mmsxx.virtualHeight; // 既定の裏画面サイズ

const bg = mmsxx.layer(0);             // レイヤー取得 (0 が奥)
bg.draw(x, y, rgbaImage);            // RGBA画像を裏画面へ描画(自動MSX変換)
bg.draw(x, y, img, true, { flipX: true });   // 反転して描く
bg.draw(x, y, img, true, { rotate: 180 });   // 180度回転(90/270は非対応)
bg.fill(color, x, y, w, h);          // 塗りつぶし (color 0 = 透明クリア)
                                     // 位置と大きさは 8 ドット単位に丸められる
bg.fill(color, x, y, w, h, true);    // 第6引数 true で 1 ドット単位のまま塗る
                                     // (1 ドットずつ細くなる帯などに使う)
bg.setRepeat(false);                 // 画面の端で裏画面を繰り返さない
                                     // (既定は繰り返す。星空などはそのままでよい)
bg.setRepeat(false, true);           // 横だけ繰り返さない / 縦は繰り返す
bg.clear();                          // 全面透明クリア
bg.print(x, y, 'HELLO', 15);         // 内蔵フォント(1文字8x8)で文字描画
                                     // 英数字・記号のほかに **カタカナ**も持っている
                                     // (濁点は実機と同じく「カ」+「゛」の 2 文字)
                                     // 括弧 ( ) も入っている
bg.scroll(x, y);                     // スクロール位置設定(ラップする)
bg.scrollBy(dx, dy);                 // 相対スクロール
bg.snap = 8;                         // 表示スクロールを8ドット単位に量子化(0=滑らか)
bg.visible = false;                  // レイヤー表示ON/OFF
bg.width; bg.height;                 // このレイヤーの裏画面サイズ

// ---- スプライト ----
const sp = mmsxx.sprite(rgbaImage);           // 生成 (個数制限なし)
const sp1 = mmsxx.sprite(img, { colors: 1 }); // 単色スプライト(実機風)
const sp2 = mmsxx.sprite(img, { colors: 2 }); // 2色(スプライト2枚重ね風)
sp.x = 100; sp.y = 50;               // 画面座標 (256x192)
sp.priority = 10;                    // 大きいほど手前
sp.visible = false;
sp.image = otherImage;               // 差し替え(アニメ用)
sp.flipX = true;                     // 左右反転
sp.flipY = true;                     // 上下反転
sp.rotate = 90;                      // 0 / 90 / 180 / 270 (時計回り)
sp.blink = 2;                        // 2フレームに1回だけ出す(実機風のちらつき)
sp.blinkOn = 2; sp.blink = 4;        // 2コマ出て2コマ消える(2:2)。既定は blinkOn=1
// ちらつきの位相は既定で「エンジンが自動でずらす」。同じ blink のものが
// いっせいに消えず、少ない枚数を回しているように見える。
sp.blinkPhase = 0;                   // 数字を入れると明示指定(0 でそろえれば同時に消える)
sp.blinkPhase = null;                // 自動に戻す
// パラパラアニメ(通常スプライト・BGスプライトの両方で使える)
sp.frames = [img0, img1, img2];      // image のかわりに順番に表示する
sp.frameRate = 6;                    // 6フレームごとに次のコマ
sp.framePhase = 0;                   // 同じ絵でもコマをずらせる
sp.frameLoop = false;                // 最後のコマで止める(1回だけのアニメ)
// 色の入れ替え(同じ絵から色違いを作る。絵を何枚も定義しなくてよい)
sp.colorMap = { 2: 7, 3: 5, 12: 4 }; // { 元の色: 新しい色 } パレット番号で指定
sp.colorMap = null;                  // 入れ替えなしに戻す
mmsxx.removeSprite(sp);

// ---- BG スプライト ----
// 通常スプライトより奥。位置は 8 ドット単位に丸められ、
// 大きさと枚数に制限はない(大きな敵や小惑星向け)。
// priority はレイヤーと同じ空間。n = 「レイヤー n の手前」。
const big = mmsxx.bgSprite(rgbaImage);
big.priority = 3;                    // レイヤー3の手前・レイヤー4の奥
big.x = 64; big.y = -32;
big.flipX = true;                    // 反転と 180 度回転のみ有効
mmsxx.removeBgSprite(big);

// ---- 画像 ----
// rgbaImage は {data: Uint8Array(RGBA), width, height} か ImageData。
const img = mmsxx.convert(rgbaImage);              // 明示的に事前変換もできる
MMSXXEngine.imageFromBase64(b64, w, h);          // gamedata.js の画像を復元

// ---- 走査線と色の置き換え ----
// 絵を 1 ライン おきに間引く「走査線」は、BG スプライトにも BG パーツにも付けられる。
// null = 入れない / 0 = 奇数行を抜く / 1 = 偶数行を抜く。
// 毎コマ 0 と 1 を入れ替えると、抜ける行が交互に動く。
sprite.scanline = (mmsxx.frame >> 1) & 1;                // スプライト
layer.draw(x, y, img, true, { scanline: 0 });          // BG パーツ
layer.scanline = (mmsxx.frame >> 1) & 1;                 // レイヤーまるごと
// STAR FABLE のエンディングでは 3 コマで 1 まわり(1:1:1)にしている。
//   位相 0 -> 位相 1 -> レイヤーごと消す
// 消す 1 コマをはさむと、位相の入れ替わりだけのときより落ち着いて見える。
// 抜いた絵は絵ごとにキャッシュされる(毎フレーム間引き直さない)ので、
// 非力な端末でも描く手数は元の絵と変わらない。
// 色番号の置き換えも同じように使える。1 枚の絵を色ちがいで描き分けられる。
layer.draw(x, y, img, true, { colorMap: { 2: 7, 3: 5 } });
// 1 ライン おきのディザ + 走査線の位相ずらし で、15 色にない中間色を目で作れる。

// ---- サウンド ----
mmsxx.audio.defineBGM('main', [mml1, mml2, mml3]); // トラックごとの MML 配列
mmsxx.audio.defineSE('shot', mml);
mmsxx.audio.playBGM('main', true);     // 第2引数 = ループ
mmsxx.audio.fadeOutBGM(1.5);           // 秒数をかけて消す
mmsxx.audio.playJingle('fanfare');     // ジングル(ファンファーレなど)。
                                       // **BGM は止めず、鳴っているあいだだけ黙る**ので、
                                       // 終わると曲の続きが聞こえる(頭出しし直さない)
mmsxx.audio.jingling;                  // ジングルが鳴っているか
mmsxx.audio.stopBGM();
// SE は「空いている音があればそこで鳴る」。ショットと爆発が同時に鳴ることもある。
// 同時に鳴らせる音の数は new MMSXXEngine(canvas, { maxVoices: 8 }) で決める
// (エンジン側に上限は無い。BGM が使っているぶんも数に入る)。
// 空きが足りないときは、優先度の低い SE を止めて場所を作る。
// 自分より高い優先度しか鳴っていなければ、その SE は鳴らさない。
// ノイズ(爆発など)は本数が別枠。new MMSXXEngine(canvas, { maxNoise: 2 }) で決める
// (既定 1 = 実機の PSG と同じ。数えるのは SE のぶんだけで BGM のドラムは別)。
// あふれたときは優先度の低いノイズ SE を止める。
mmsxx.audio.playSE('shot');                       // ふつうの SE
mmsxx.audio.playSE('laser', 3);                   // 大事な SE
mmsxx.audio.playSE('fanfare', 9, { exclusive: true }); // 独り占め(他を全部止める)
mmsxx.audio.stopSE();

// ---- しゃべる (TALK) ----
// 録音データは持たない。鳴らすときに**フォルマント合成**で波形を作る。
// 音源(インパルス列 / ノイズ) -> 共鳴器 3 つ(母音の口の形) という組み立て。
// カタカナ(ひらがなも可)を渡すとモーラに分けて並べる。
// 空白と句読点は間になり、「ー」は伸ばし、「ッ」は詰まる。
mmsxx.audio.defineTalk('king', 'ワタシハ ウチュウノ テイオウ コゾリテ。');
mmsxx.audio.playTalk('king', 5);       // 第2引数は SE と同じ優先度
// 既定はわざと粗い(8 ビット機の声にする)。オプションで変えられる:
//   rate  書き出すサンプリング周波数(既定 8000)。低いほど粗い
//   bits  量子化ビット数(既定 6)。低いほどざらつく
//   pitch 声の高さ Hz(既定 120) / speed しゃべる速さ(既定 1)
//   fall  語尾へ向かって下がる量(半音。既定 3) / growl だみ声(既定 0)
mmsxx.audio.defineTalk('boss', 'タオサレハセン', { pitch: 92, bits: 4, growl: 0.7 });
// 作った波形は名前ごとにキャッシュされる(2 回目からは作り直さない)。

// ---- 入力 ----
mmsxx.input.isDown('ArrowLeft');       // KeyboardEvent.code で指定
mmsxx.input.wasPressed('Space');       // このフレームで押されたか

// ---- メインループ ----
mmsxx.run((m) => { /* 60fps で呼ばれる */ });
mmsxx.stop();
mmsxx.step(n);                         // デバッグ用に n フレーム手動で進める
```

## 反転と回転

1 枚の絵から向き違いを作れます。変換結果はキャッシュされるので、
毎フレーム参照しても作り直しは起きません。

### 素材づくりの小道具

`assets-src/makedata.mjs` には MML を半音単位で移調する `transposeMML(mml, n)` があります。
曲のキーを変えたいときは、書き直さずにこれを通します。

| 対象 | 左右反転 | 上下反転 | 90 / 270 度 | 180 度 |
|---|---|---|---|---|
| 通常スプライト | ○ | ○ | ○ | ○ |
| BG スプライト | ○ | ○ | × | ○ |
| レイヤーへの描画 | ○ | ○ | × | ○ |

90/270 度は「横 8 ドット 2 色」が縦方向の制約に変わってしまうため、BG では使えません
(指定しても無視されます)。

## MML リファレンス

MSX BASIC の PLAY 文風です。

| コマンド | 意味 |
|---|---|
| `c d e f g a b` | 音符。直後に `+`/`#`(半音上げ)、`-`(半音下げ)、数字(音長)、`.`(付点) |
| `r` | 休符 |
| `o<n>` | オクターブ 1..8 (`o4` の `a` = 440Hz) |
| `>` `<` | オクターブ上げ / 下げ |
| `l<n>` | デフォルト音長 (4=四分音符) |
| `t<n>` | テンポ (四分音符/分) |
| `v<n>` | 音量 0..15 |
| `q<n>` | ゲート 1..8 (8=フルレングス、スタッカート表現用) |
| `&` | タイ (直後の音符の長さを直前の音に足す) |
| `[ ... ]<n>` | 繰り返し (n 省略時 2 回、ネスト可) |
| `@<n>` | 波形 0..7 |
| `@e<n>` | エンベロープ 0..5 |
| `@d<n>` | デチューン(重ねる音のずれ。0 で無効) |
| `@v<n>` | ビブラート(0 で無効) |
| `@s<n>` | エコー(0 で無効) |

波形は `@0`〜`@3` がパルス(デューティ 12.5 / 25 / 50 / 75%)、`@4` 三角波、
`@5` ノコギリ波、`@6` サイン波、`@7` ノイズです(旧記法の `@n` もノイズ)。

```js
mmsxx.audio.defineBGM('main', [
  't150 q7 v12 l8 @1 @e1 @s3 o5 [cdefgab>c]2',   // メロディ (25%パルス+エコー)
  't150 q8 v12 l8 @4 @e0 o2 [c>c<c>c<c>c<c>c]2', // ベース (三角波)
  '@7 @e2 t150 l8 [v12o2c v6o6c v10o4c v6o6c]4', // ドラム (ノイズ)
]);
```

トラックの長さがそろっていないとループでずれます。`npm run checkbgm` で全曲を確認できます。

## アセットの作り方

`assets-src/makedata.mjs` にドット絵・曲・出現テーブルを**コードとして**書き、
`npm run data` で `game/gamedata.js` を生成します。

生成時に**絵素材のチェック**が走ります(警告のみでビルドは止まりません)。

- BG 素材: 横 8 ドット 2 色(背景色込み)に違反していないか
- スプライト素材: 3 色以上を使っていないか、サイズが 8 か 16 の倍数(64 まで)か

### コツ

- **BG 素材は「行ごとに違う 2 色」を積極的に使う**と中間色に見えて豪華になります。
  市松模様はルール違反になりがちなので使いません
- 大きなメカは 8x8 のタイル(装甲板・継ぎ目・ボルト・排気口・関節・シリンダー・
  センサー・警告ストライプ・面取りなど)を組み合わせて作ります
  (`MECH_TILE` と `buildMech()`)。1 タイル 2 色なので制約が自動的に守られ、
  パーツごとに色を変えられます
- 反転で済むものは素材を持たず、`flipX` などで向きを変えます

## 速さについて

- 1 フレーム(更新 + 合成)は実測 **0.5ms 前後**(PC。16.7ms の予算に対して 3% ほど)
- 重いのは画面の合成で、そのうち 8 割ほどを占める
  (256x192 の全ピクセルをレイヤーの枚数ぶん走査するため)
- **何も描かれていないレイヤーは合成そのものを飛ばす**ので、
  使っていないレイヤーを持っていても無駄にならない
  (全レイヤーが空なら 0.53ms → 0.11ms)

## 制限・メモ

- 音はブラウザの制約により、最初のキー入力以降に有効化されます
- `window.mmsxx` にエンジンが公開されています(デバッグ用)。
  `mmsxx.stop()` のあと `mmsxx.step(n)` で手動フレーム送りができます
- ブラウザのタブが非表示のあいだは `requestAnimationFrame` が止まるため、
  自動テストで進めたいときは `stop()` + `step(n)` を使ってください
