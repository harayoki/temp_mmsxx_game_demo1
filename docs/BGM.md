## 設計メモから作る

**曲ごとに紙を 1 枚作り、それだけを見て書く。**
参考にした曲があっても、紙に残るのは「テンポ 168・16 小節・追われる感じ」という、
誰のものでもない情報だけになる。写す余地がそもそも無くなるのが狙い。

```
用途       ボス戦
テンポ     168
拍子       4/4
長さ       16 小節ループ + 前奏 4
調         ニ短調
ch1        旋律。8 分主体、跳躍を多めに
ch2        対旋律。3 度下。サビだけユニゾン
ch3        ベース。アルペジオで厚く。裏拍にこだま
noise      2 拍目と 4 拍目
雰囲気     追われている感じ。休符を作らない
```

**機械を替えるときにも効く。** ファミコン風やビープで作り直すとき、
同じ紙から起こせば「同じ曲の別の機械版」になる。MML を移植するより素直。

## 借りてよいもの / いけないもの

| 借りてよい | 借りてはいけない |
|---|---|
| テンポ、拍子、ループの長さ | **旋律**。数小節でもそれと分かるもの |
| 構成（A-B-A-サビ、前奏 4 小節） | 特徴的なリフやフレーズ |
| チャンネルの役割分担 | 伴奏の型と旋律が一体になった特徴 |
| 音の詰めかた（16 分の刻み、休符の置きかた） | |
| 音域の配りかた、和音の厚み | |
| 書きかたの技（アルペジオでベースを厚く、3 声目にこだま、ノイズで打楽器） | |

**和音の並びそのものは、ありふれたものなら問題にならない**
（カノン進行や小室進行を使っても誰も咎めない）。
危ないのは**旋律**と、**旋律と伴奏が一体になった特徴**。

## 引用について

**音楽には「何小節まで」という線が無い。** 判断は長さではなく 2 点で決まる。

- **類似性** … 似ているか
- **依拠性** … 聴いて作ったか

有名な 2 小節のフックは危なく、ありふれた音階の 8 小節は問題にならない、
ということが起こる。「4 小節までなら大丈夫」は俗説。

法律上の「引用」（著作権法 32 条）は要件が厳しい。主従関係（引く側が主）、
明瞭に区別できること、必要最小限、出所の明示。
**ゲームの BGM の中で旋律を引くと、区別がつかず溶けてしまう**ので、
この要件は満たしにくい。日本にはパロディの例外も無い。

### 意図のある引用が成り立つ道

| 道 | 例 |
|---|---|
| **パブリックドメイン** | このゲームがすでにやっている（下） |
| **許諾を取る** | 同人・インディーでも、連絡すれば通ることがある |
| **自分の曲を引く** | 過去作や、同じ作品の中の旋律を持ってくる。**いちばん強い** |
| **構造だけ借りる** | 上の設計メモ |

### この作品での使いかた

すでにパブリックドメインの曲を、意味のある場所に据えてある。

| 曲 | 場面 |
|---|---|
| ベートーヴェン「月光」 | ゲームオーバー |
| 同「運命」（長調に編曲） | ステージクリア |
| 同「エリーゼのために」 | タイトル |

**この 2 つ（負けの主題・勝ちの主題）を自分の曲の中で変形して再登場させる**と、
引用というより**作品内の主題**になる。元がパブリックドメインなので自由に変形できるし、
場面と結びついているぶん意味も強い。

例: ラスボスの曲に「運命」の 4 音を刻みだけ残して埋め込む。

## 作るときの手順

1. 設計メモを書く（上の形）
2. MML で書く。トラックの長さをそろえる（ずれるとループで崩れる）
3. `npm run checkbgm` で全曲を確認する
4. サウンドテストで聞く。全曲再生（`- ALL -`）で通しの流れも見る

**参考にしたい曲があるときは、MIDI か MML のデータ、または言葉での説明**を渡すこと。
Claude は音を聞けないので、mp3 を渡されても分析できない。
データがあれば、テンポ・構成・音域・密度を数字で取り出して、そこから全部書き直せる
（どこが特徴的で避けるべきかも指摘できる）。

## 既存の曲データを読み込む

[TODO.md](TODO.md) の M-10 を参照。方針だけ書いておくと、

- **変換は素材を作るときに 1 回**。ランタイムにコンバータは載せない
- **MSX の駆動系は、MML のソースが残っているものだけ**
- **VGM などは対応しない**。難しい曲は音声ファイル（mp3）で鳴らす
- **曲そのものは作った人のもの**。駆動系がフリーでも、配られている曲を公開版に載せるなら許可が要る
